# 数据隔离：连着上十几讲会不会串



> 从 SKILL.md 挪出来的细节。SKILL 里只留结论，这里讲为什么。



### 连着上十几讲，会不会串？



**不会。** 每一讲的数据是三套独立的东西：



| 存什么 | 存哪 | 讲与讲之间 |

|---|---|---|

| 满分、大题名称/题数/分值 | `班级名单/<班级>.txt` 的 `@` 行 | **换课次时整组清空**，本讲重写 |

| 分数、错题号 | 同上，每个学生一行 | **换课次时没交卷的人清成待登分**，不留上一讲的分数 |

| 答案、照片、题库 | 按 `<课次>` 各自一个文件/目录 | 天然隔离 |

| 成绩表、报告、巩固单、群发 | 按 `<课次>` 各自一个子目录 | 天然隔离 |

| 全班成绩总表 | `成绩表/<班级>/` 一张表，一列一次课 | 累加，不回改历史列 |



`ingest.py` 一进来先比 `@课次` 和这次的课次：不一样就认为换讲了，

把上一讲的满分/题型/分值**全部丢掉**，逼着本讲重新给。所以：



- 第五讲 4 个大题 40 分、第六讲 3 个大题 40 分、第七讲 5 个大题 100 分——三讲互不影响

- 第二讲只交了 2 份卷子，另外 25 人被报成「没交卷」，不会带着第一讲的分数混进来

- 唯一的例外是 `成绩历史.csv`，它就是要跨讲累加，用来算「比上次进步几分」



环境变量 `KCFK_ROOT` 指到工作区，所有脚本都认：



```bash

export KCFK_ROOT="/path/to/工作区"       # Windows 上写 E:/你的工作区

```
