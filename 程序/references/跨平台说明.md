# 跨平台说明（Mac / Windows / 全新电脑）



## 一句话结论



**老师只要装了 WorkBuddy，就不需要额外装任何东西。** Windows、Mac 都能跑。



因为 WorkBuddy 自带 Python 运行时——实测这个会话里 `bash` 的 `python` 就是：



```

C:\Users\<用户>\.workbuddy\binaries\python\versions\<版本号>\python.exe

```



Mac 上同理，只是路径变成 `~/.workbuddy/binaries/python/versions/*/bin/python3`。

**Python 不用老师装，也不用管版本。**



---



## 第一次用会做什么（老师无感）



`bootstrap.py` 自动：



1. 在技能目录建 `.venv`（隔离环境，不污染系统）

2. 装 3 个包：`openpyxl` / `python-docx` / `Pillow`（约 26 秒）

3. 直连 PyPI 失败会自动换清华镜像重试



**这一步需要联网一次。** 之后离线也能跑（除了 AI 看图那步本来就要联网）。

## 三个平台的差异，以及怎么处理



| 项 | Windows | macOS | 处理方式 |

|---|---|---|---|

| 解释器命令 | `python` | `python3`（可能没有 `python`） | SKILL.md 写明两个都试 |

| 路径分隔符 | `\` | `/` | 全部用 `pathlib`，不拼字符串 |

| 中文字体 | `msyh.ttc` / `simhei.ttf` | `PingFang.ttc` / `Hiragino Sans GB` | `fonts.py` 按「技能自带 → 系统」顺序找 |

| 虚拟环境位置 | `.venv/Scripts/` | `.venv/bin/` | `os.name` 判断 |

| HEIC 照片 | 需 `pillow-heif` | `sips` 命令自带 | `转jpg.py` 优先用 sips |

| Word 字体名 | 微软雅黑 | PingFang SC | `fonts.docx_font_name()` 按平台返回 |

| 文件锁 | Excel 打开会锁文件 | 不锁 | `填模板.py` 已捕获 PermissionError，改名重存 |



## 不需要老师装的东西



- ❌ Python（WorkBuddy 自带）

- ❌ Office / WPS（openpyxl 和 python-docx 不依赖 Excel/Word）

- ❌ 中文字体（三平台系统都自带；实在没有可以往 `<SKILL>/fonts/` 丢一个 ttf）

- ❌ 任何 API key（AI 自己看图）



## 会占用的资源



- 磁盘：技能约 45MB（主要是 `.venv`），产物按班级大小另算

- 权限：只读写老师指定的工作区文件夹（`照片/`、`成绩表/`…），不碰系统目录

## 如果 Mac 上真出问题，先查这三处



1. **`python: command not found`** → 换 `python3`

2. **反馈单中文是方块** → `fonts.py` 没找到字体。把任意中文字体放到 `<SKILL>/fonts/` 即可

3. **照片读不到** → iPhone 的 `.HEIC`，先跑 `python 转jpg.py --目录 "照片/班级/课次"`
