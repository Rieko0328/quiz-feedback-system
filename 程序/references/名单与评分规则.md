# 名单文件与评分规则

## 名单文件 `班级名单/<班级>.txt`

**这是整个系统唯一的事实来源。** 成绩、话术、小任务、反馈单全部从这里读。

```
@班级: 五1班
@课次: 第5讲L95-96
@满分: 100
@重点线: 60

张三 85 3,7,10
李四 100 全对
王五 92 7
郑十一 缺考
```

- 学生行三列：`姓名 分数 [错题号]`，空格分隔
- 错题号随便写：`3,7,10` / `3、7、10` / `错3,7,10` / `3 7 10` 都认
- 全对写 `全对`，缺考写 `缺考` 或 `请假`
- `#` 开头是注释行（**只能在行首，不能加在学生行末尾**）

### `@` 元数据（都可选）

| 键 | 作用 | 默认 |
|---|---|---|
| `班级` `课次` | 决定产物目录名 `<班级>_<课次>` | 必填 |
| `满分` | 卷面总分，决定档位折算 | 100 |
| `重点线` | **低于它才在话术里给家长派家里任务** | 60（内部 FOCUS_SCORE=30，按满分折算） |
| `大题名称` | 分项名，逗号分隔，对应 `大题扣分.json` 的「一二三」 | 无 |
| `大题题数` | 每个大题的题数，用于错题号换算 | 无 |
| `考试名称` | 话术里怎么说这场考试 | 「月考试卷」 |
| `称呼` | 话术里对家长的称呼后缀 | 「家长」 |
| `家长风格` | `亲和` / `安抚` / 空（严格） | 空 |
| `特殊学生` `严正学生` `安心学生` | 逗号分隔，指定某人用专属话术模板 | 无 |
| `同家长` `双胞胎` | 逗号分隔，同一家长的孩子合并成一份话术 | 无 |
| `知识点库` | 指定用哪个考点库 | 自动挑 |
| `任务模式` | 小任务的取向 | 无 |

## 档位（按**得分率**折算，适配任意满分）

| 得分率 | 档位 |
|---|---|
| 100% | 满分 |
| 90–99% | 优秀 |
| 80–89% | 良好 |
| 70–79% | 合格 |
| 60–69% | 待提升 |
| < 60% | 需重点关注 |

> 40 分制考 32.5 = 81.25% → **良好**，不会被当成「需重点关注」。
> 这是支持 40 分卷的关键，不要用绝对分数判断档位。

---

## 扣分校验（本系统准确率的核心）

**各大题扣分之和 = 满分 − 分数**

- 相等 → 正常
- 不相等 → 差额记进 `大题扣分.json` 的 `"未定位"` 字段
- 例：`{"一": 2, "二": 0, "三": 6, "未定位": 4}` 表示还有 4 分没定位到哪个大题

**为什么要这样**：AI 读分和老师手写扣分是两条独立证据。
两条对得上才敢发；对不上就说明至少有一条错了，必须让老师看一眼。

`ingest.py` 会自动算这个，AI 不需要自己算，**但也不许为了让它能对上而改数字**。

---

## 记分约定

- 小数支持：`36.5` 正常存
- 缺考：`分数 = null`，**不参与平均分、及格率、排名**
- 名单里重名：自动加 `(2)` 区分，话术和照片不会互相覆盖
- 姓名前的字母前缀（如 `A李小明`）只用于名单排序，**不进家长话术**
