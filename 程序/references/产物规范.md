### 6.4 产物长这样（按公司群发系统的要求排的，别改）



```

<工作区>/                              ← 顶层 7 个目录

├── 班级名单/<班级>.txt

├── 课测答案/<课次>.txt

├── 照片/<班级>/<课次>/                IMG_0001.jpg…  +  已改名/姓名.jpg

├── 题目/<班级>_<课次>/题库.json

├── 成绩表/<班级>/

│   ├── <课次>_成绩表.xlsx

│   └── <班级>_成绩总表.xlsx            ← 每讲自动多一列

├── 群发/<班级>/<课次>/

│   ├── 资料/                          张小明.jpg  张小明.docx（巩固单）

│   └── 群发表.xlsx                    ← 和资料分开，群发时不混进去

└── 生成结果/

    ├── 通用练习/<课次>/                背诵单.docx  专项练习.docx

    ├── 话术/<班级>/<课次>.docx

    ├── 诊断报告/<班级>/<课次>/<姓名>_诊断报告_第1页.png · 第2页

    ├── 巩固单/<班级>/<课次>/<姓名>_巩固练习.docx

    ├── <班级>_<课次>/                  过程文件：

    │   ├── 家长反馈话术.txt            3 条消息，<<<SPLITn>>> 是分条标记

    │   ├── 大题扣分.json               分项扣分，话术/报告靠它定位考点

    │   └── 汇总报告.md

    └── 历史/成绩历史.csv              跨周累计，删了进步追踪就断

```



> 话术 docx、诊断报告、巩固单、群发内容都是**搬**过去的（不是复制），

> 过程目录里不会留重复件；想两边都留加 `归档.py --保留副本`。



> **群发目录内部是平铺的**：`张小明.jpg` `张小明.docx` 并列，不再往下建个人文件夹，

> 因为公司系统按文件名匹配学员。课次这一层文件夹是给人看的，别省。



## 6.6 巩固单的排版与题量



### 结构（脚本固定，别改）



```

第 1 页  一、要背的      ← 他这次错的考点，每个 2-3 条要点

第 2 页  二、要做的      ← 每题只有「我的答案：____」

第 3 页  三、答案与解析   ← 另起一页，绝不跟着题目走

         老师的话

```



**2-4 页**：6 题以内 3 页（背诵/题目/答案各一页），8 题以上 4 页。

背诵不足 3 个考点时不分页，会短一些。



### 题量：按成绩定，你别硬凑



| 得分率 | 出几道 |

|---|---|

| ≥95% | 3 |

| 85-94% | 6 |

| 70-84% | 8 |

| <70% | 12 |



再按失分考点数收敛（错得少就少出）。**题库里题多它也只取前 N 道**。



### 单跑某一个人



```bash

# 从题库抽

python <SKILL>/scripts/错题巩固单.py --班级 五年级A班 --学生 张小明 --题库 "题目/五年级A班_五年级第五讲/题库.json"

# 或者给他单独指定题目

python <SKILL>/scripts/错题巩固单.py --班级 五年级A班 --学生 张小明 --题目 "题目/五年级A班_五年级第五讲/张小明.json"

```



两份数据都没有时降级成「抄写 + 默写」版，不出选择题——不会报错，也不会停下来等你。

### 6.3 巩固单的题：靠题库抽，不用一人写一份



```bash

# 你只需要写一份题库，全班自动抽

题目/<班级>_<课次>/题库.json

```



```json

{

  "考点": {

    "疑问词": {

      "背诵": ["问人 Who；问物/职业 What；问地点 Where；问时间 When",

               "问数量：可数 How many + 复数，不可数 How much"],

      "题": [

        {"题干": "— ______ is your father? — He is a doctor.",

         "选项": ["A. Who", "B. What", "C. Where", "D. How"],

         "答案": "B", "解析": "问职业用 What，Who 问的是姓名身份。"}

      ]

    }

  }

}

```



**题库 key 用原子考点**：答案文件里写的是 `疑问词,划线提问` 这种复合考点，

拆成 `疑问词` 和 `划线提问` 两个 key 建库，脚本会自动对上。



每个孩子拿到的是：

- **背诵** = 他这次失分的考点，要点从题库对应条目取

- **题目** = 从这些考点的题池里轮转抽，题量按得分率算（3-12 道）

- 同班两个孩子题目不会完全一样（按学生序号错开起点）



**一个考点至少写 3-4 道题**，否则同分段的几个孩子会撞同一道。



优先级：`题目/<班级>_<课次>/<姓名>.json`（个别孩子想单独指定）> 题库抽题 > 抄写默写版。



> 完整目录树、巩固单排版与题量，见 `references/产物规范.md`。

> 老师实际只用碰两个地方：`群发/`（要发的）和 `成绩表/`（看分数的）。

## 8. 交付



老师最后要拿走的其实只有两样：



```

群发/<班级>/<课次>/资料/       ← 全班孩子的 姓名.jpg + 姓名.docx，一个文件夹交给群发软件

群发/<班级>/<课次>/群发表.xlsx  ← 填好分段话术，导入群发软件

```



别的都是给老师自己留档的（成绩表、汇总、诊断报告、巩固单、话术 docx）。



1. 用 `present_files` 推关键文件：成绩表、已填群发表、诊断报告代表几张、巩固单一份

2. 告诉老师产物在工作区哪个路径，他自己也能翻

4. 一句话说清「资料文件夹 + 群发表，这两样拿去软件里就能发」，别让老师猜
