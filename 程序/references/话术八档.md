### 八档分别是干什么的（别合并，各有各的用处）



| 档 | 层级 | 给哪种孩子 / 家长 | 话术开头 |

|---|---|---|---|

| **标准** | 全班 | 大多数 | 按分数档位说 |

| **亲和** | 全班 | 低年级、家长年轻 | 更软、多鼓励 |

| **安抚** | 全班 | 家长普遍焦虑 | 「分数您先不用往心里去」 |

| **进步** | 个人 | 这次明显上来了 | 「比上次提高了 11 分，这个幅度是很明显的」 |

| **退步** | 个人 | 这次明显下滑 | 「比上次少了 9 分，这个落差我看到了，别慌」 |

| **危机感** | 个人 | **课上能跟、回家自己学不进去**（依赖人带） | 「分数先放一边，有个现象您需要知道」 |

| **严正** | 个人 | **上课没听、回家没背**（态度问题） | 「这次我想跟您认真聊一次」 |

| **安心** | 个人 | 家长容易紧张、容易过度反应 | 只给一件能做的小事 |



> **为什么危机感和严正不合并**：治的是两回事。危机感治「离不开人带」——孩子肯学但方法不对；

> 严正治「压根没学」——卷面空着、交代要背的没背。前者要指方法，后者要请家长配合。

> 合并了就只能说一半，两头都不准。

>

> **为什么亲和和安抚不合并**：亲和是全班语气偏软（低年级都这样），

> 安抚是针对「家长会慌」这一件事，话术要先把情绪接住。场景不同，不是程度不同。

>

> **进步版不是「考得好就用」**：一直考得好的走标准。进步版给「这次明显上来了」的孩子——

> 他已经尝到甜头，这时候要让他知道甜头怎么来的，别再念剩下的毛病。

> **考得差也不等于该上危机感/严正**：那是治态度和方法的，不是治分数的。



### 怎么设



```bash

python <SKILL>/scripts/名单设置.py --班级 五年级A班 --查看

python <SKILL>/scripts/名单设置.py --班级 五年级A班 --进步 王小明

python <SKILL>/scripts/名单设置.py --班级 五年级A班 --退步 李小红

python <SKILL>/scripts/名单设置.py --班级 五年级A班 --特殊 张三

python <SKILL>/scripts/名单设置.py --班级 五年级A班 --严正 李四

python <SKILL>/scripts/名单设置.py --班级 五年级A班 --安心 王五

python <SKILL>/scripts/名单设置.py --班级 五年级A班 --风格 安抚

python <SKILL>/scripts/名单设置.py --班级 五年级A班 --清空 退步

```



`--特殊` 就是危机感版（`@特殊学生`），参数名没改，改了对老工作区不兼容。



**不要手改名单 txt。** 用这个脚本，它会核对名字在不在班里。



### 建班时只管一件：全班语气



> 这个班的家长，整体上更像哪一种？

> - `照常说就行`（标准）

> - `偏小龄，说话软一点、多鼓励`（亲和）

> - `容易焦虑，得先给台阶`（安抚）



一次定下来，后面不用再问。个人级的版本每次课测按上面的规则临时问。
