# 提问卡：每处该问什么、选项怎么写



> 从 SKILL.md 挪出来的明细。原则和约束留在 SKILL 0.5。



### 必须用提问卡的（这几处最容易问崩）



| 时机 | 卡片怎么写 |

|---|---|

| 这次是哪个班 | 列出 `新建班级.py --列出` 里的班，一次最多 4 个；超过就分两轮 |

| 这讲有答案吗 | `有，我发你` / `没有` |

| 人来少了 | **一个孩子一组**：`缺考（下次还来）` / `退费或转班走了` |

| 人多了 | **一个孩子一组**：`来试听的，只记这一次` / `转班进来的，正式入班` / `新报名` |

| 这次要生成哪些 | 多选：通用练习 / 诊断报告 / 巩固练习，见第 6 节 |

| 这讲有没有特殊情况 | 多选：`没有照常` / `有几个孩子要单独说法` / `要统一加一句话` / `这次不群发` |

| 我读错的名字要不要改 | `按名单改` / `我来告诉你正确的` |

| 删班要不要连产物 | `一起清掉` / `先留着` |



### 不要用提问卡的



**只有这四类，其余一律做成点选。**



| 情况 | 为什么 | 怎么办 |

|---|---|---|

| 班叫什么名字 | 自由文本，选项穷举不了 | 文字问，让老师一行一个 |

| 贴照片、给名单 xlsx、给群发表 | 是附件，不是选项 | 文字要，等文件 |

| 「第 3 题和第 7 题错了」这种 | 内容太长，卡片塞不下 | 文字对话，改完再收一次确认卡 |

| 展示 40 人的核对表本身 | 卡片塞不进表格 | 表格**用文字/图片发**，但**确认用卡片**（`都对，往下走` / `有几个要改`） |



> **分值、题数、班数、要不要某样产物、谁的版本、缺考还是退费——全都能点选。**

> 拿不准的时候问自己：这个答案能不能提前列成 2-4 个？能就做成卡片。



### 约束



提问卡一次最多 **4 个问题**、每个问题 **2-4 个选项**。

超了就拆成两轮，别硬塞；**重要的事单独问一轮**，不要和别的问题挤在一起。



选项文字要写**老师嘴里的说法**，不要写系统术语：

写「缺考（下次还来）」不写「状态=absent」。
