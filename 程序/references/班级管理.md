# 班级管理：新建 / 查看 / 删除



> 从 SKILL.md 挪出来的明细。建班时（第一次）读一次就够。



### 班级本身怎么改：新建 / 删除 / 看有哪些



| 要做的事 | 命令 | 说明 |

|---|---|---|

| 新建一个班 | `新建班级.py --从表 "学员列表.xlsx" --班级 周五慢班` | 从企微表建，只要名单 |

| 看有哪些班 | `新建班级.py --列出` | 班长什么样、几年级、填了几个人 |

| 删掉一个班 | `新建班级.py --删 --班级 周五慢班` | 名单移到 `_已删除/`，**同时清掉这个班在成绩历史里的记录** |

| 连产物一起清 | 加 `--连产物` | 照片 / 成绩表 / 群发 / 报告一起移到 `_已删除/` |



**删班一定会做的一件事**：把这个班在 `成绩历史.csv` 里的行删掉。

不删的话，以后建一个同名班，第一讲就会显示「比上次进步 12 分」——

那个「上次」是上一个班的成绩，纯粹串了。



**没有真删。** 名单和产物都进 `工作区/_已删除/<班级>_<时间戳>/`，按原目录结构摆好，

反悔了直接搬回去。老师问「删了还能恢复吗」，答案是能。



**删班前要问一句**（卡片）：



> 这个班要删掉，产物（照片、成绩表、群发、报告）要一起清吗？

> - `一起清掉`（推荐：确定不带了）

> - `先留着`（只是不想再出现在班级列表里）



不确认就别加 `--连产物`——删了报告，家长那边要补发就麻烦了。

> 每次课测只是往这份名单里写分数，**不重建班**。
