# 课测反馈系统

> 一个英语老师每周 90 分钟的家校反馈工作，压到 10 分钟。

把答题卡照片丢进文件夹，系统自动认分、登分、写家长话术、出诊断报告、出针对性的巩固练习，
再归档成群发文件 —— 全部本地运行。

## 一条命令跑完全流程

```bash
python 程序/脚本/一键生成.py --班级 周日2-4
```

做的事（14 人的班约 **8 秒**）：

```
1. 成绩表 + 家长话术 + 汇总报告
2. 通用练习（背诵单 / 专项练习，缺考的孩子补）
3. 诊断报告（每人 2 页图）+ 巩固练习（每人一份 docx，按他自己的错题出）
4. 群发打包（照片和练习改成孩子名字，直接拖进企业微信）
5. 整理成标准目录
```

## 产物长什么样

### 每人收到三样

```
群发/<班级>/<课次>/资料/
    张三.jpg              ← 答题卡照片
    张三.docx             ← 巩固练习（前面是要背的几处，后面几道题，最后一页答案）
```

> 文件名必须是 `<姓名>.jpg + <姓名>.docx` —— 公司群发系统按这个配对。

### 老师手上

| 产物 | 位置 | 内容 |
|---|---|---|
| 成绩表 | `成绩表/<班级>/` | 分数 / 档位 / 薄弱考点 / 错题号 |
| 成绩总表 | 同上 | 跨课次累加，看进步 |
| 家长话术 | `生成结果/话术/<班级>/` | 每人 3 段，可直接发微信 |
| 诊断报告 | `生成结果/诊断报告/<班级>/` | 每人 2 页 PNG：成绩与失分分布 + 丢分考点 + 老师的话 |
| 巩固单 | `生成结果/巩固单/<班级>/` | 按他这次错的考点从题库抽题 |
| 通用练习 | `生成结果/通用练习/<课次>/` | 全班一份，缺考的孩子补用 |

## 关键设计

### 1. AI 只做「读图」，判断和出题由人来做

- **读照片**：识别姓名、分数、各大题扣分、错题号
- **不读的**：满分、大题分值、题数 —— 这些卷面上是印刷体，可靠
- **交叉验证**：错题号数 × 每题分值 必须等于该大题扣分，对不上就停下来问老师

### 2. 话术全部按「这个孩子实际错的东西」生成

```
❌ 不好的写法：丢的分集中在单项选择
✅ 现在的写法：丢的分集中在现在完成时·How long
```

从「错题号 → 课测答案里的考点」一路取下来，绝不写死。

### 3. 满分 / 零失分 / 0 分 / 没数据，四种情况单独分支

踩过的坑：
- 满分的孩子在报告上看到「把错的那几处再做一遍」（他一道没错）
- 55 分和 10 分的孩子收到同一句寄语（家长一对比就看得出来）

现在寄语按档位分 **6 档**，和「满分 / 优秀 / 良好 / 合格 / 待提升 / 需重点关注」一一对齐。

### 4. 文案里不写具体文件名

群发系统把文件重命名成 `<姓名>.docx`，话术里若写「《巩固练习》（附件）」，
家长会拿着话术去群里找这个标题，找不到。

统一说「练习（附件）」。

## 题库机制

```jsonc
// 题目/<班级>_<课次>/题库.json
{
  "考点": {
    "现在完成时·How long": {
      "背诵": ["How long 问「多长时间」，答语用 for + 时间段…", "…"],
      "题": [
        { "题干": "— How long ______ you ______ here?",
          "选项": ["A. do; live", "B. did; live", "C. have; arrive", "D. have; lived"],
          "答案": "D", "解析": "since 2024 是现在完成时的标志" }
      ]
    }
  }
}
```

- 每个人的题从他的**失分考点**里抽
- 题量按得分率定（3 / 6 / 8 / 12 道），起点按学生序号错开，同班不撞题
- 考点名支持模糊匹配：`had better not be` ↔ `had better do`、`一般过去时` ↔ `一般过去时·疑问句`
- **没题库就不产出** —— 宁可不发，也不发错的

## 硬约束（挑几条）

完整 19 条见 [操作手册.md](操作手册.md)。

1. 不许编分数 —— 读不清就交人工
2. 不许跳过核对 —— 老师没确认，不出任何产物
3. 不许自己写话术 —— 由规则模板生成
4. 缺考不出专属产物，只在成绩表里标「缺考」
5. 一个孩子只出一份报告，一份练习
6. 巩固单的答案放最后一页
7. 给家长的每段话，`满分 / 零失分 / 0 分 / 没数据` 必须单独分支
8. 改完话术相关代码，必须跑 `检查硬编码.py`
