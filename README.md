# 课测反馈系统

> 一个英语老师每周 90 分钟的家校反馈工作，压到 10 分钟。

把答题卡照片丢进文件夹，系统自动认分、登分、写家长话术、出个人小任务、
归档群发文件 —— 全部本地运行，不依赖任何在线服务（除调用视觉大模型识图）。

**本项目为个人独立开发，著作权保留所有权利，详见 [LICENSE](LICENSE)。**

---

## 它解决什么问题

一周一次的课测反馈，一个 40 人的班：

| 环节 | 以前 | 现在 |
|---|---|---|
| 认名字、誊分数 | 25 分钟 | 3 分钟 |
| 逐个想话术怎么写 | 40 分钟 | 5 分钟 |
| 出针对性练习 / 小任务 | 20 分钟 | 0（自动） |
| 分文件、发家长 | 15 分钟 | 2 分钟 |
| **合计** | **约 100 分钟** | **约 10 分钟** |

难点不在「写」，在于：**这个班有 40 个孩子，但每位家长收到的那段话，
必须是单独为他家孩子写的。**

---

## 核心能力

1. **照片自动改名** —— AI 认出卷面上手写的名字，把 `IMG_1234.jpg` 改成 `张三.jpg`
2. **识别答题卡** —— 读出总分 + 每个大题的扣分，出核对表供人工确认
3. **上传课测答案（选填）** —— 进一步定位孩子**具体错在第几题、考什么考点**
4. **一人一话术** —— 按错题知识点、分数档位、性格特点单独生成，不是模板群发
5. **一人一小任务** —— 每人一份 Word，只装他自己要记的东西
6. **重命名归档 + 群发打包** —— 照片和资料统一用学生姓名，一人一个文件夹
7. **进步对比** —— 每个孩子历次课测的分数曲线和变化

---

## 一个关键设计：AI 只负责「看」，不负责「写」

| | 谁来做 | 为什么 |
|---|---|---|
| **识别**（读照片） | 视觉大模型 | 这是 AI 擅长的事：从图像里读数 |
| **话术 / 小任务** | **规则生成** | 这是要发给家长的话，必须稳定、可控、零成本 |

一旦 AI 编造出「孩子上课很积极」这种老师没见过的事，就是事故。
规则生成还有一个好处：**老师每提一条修改意见，都能固化成代码里的约束**，
改一次，以后所有班都受益。

## 快速开始

### 1. 准备

本项目**不包含 Python 运行环境**（体积太大）。你需要：

- Python 3.10+
- `pip install pillow python-docx openpyxl lxml`

或者直接使用作者发布的**便携版压缩包**（自带运行环境，解压即用，无需安装 Python）。

### 2. 目录结构

```
课测反馈系统/
├── 班级名单/          一个班一个 txt
├── 课测答案/          每次课测的答案（选填）
├── 答题卡照片/        按 班级\课次 分文件夹
├── 生成结果/          系统生成的一切（含 历史/ 成绩存档）
├── 程序/              程序本体
│   ├── 脚本/          11 个 Python 脚本
│   ├── web/           网页版前端
│   ├── app.py         命令行版入口
│   └── web_server.py  网页版服务
├── 识别配置.txt       填你的 API key
├── 启动.bat           命令行版
└── 网页版.bat         网页版
```

### 3. 配置

复制 `识别配置.example.txt` 为 `识别配置.txt`，填上你自己的 API key：

```ini
api_base  = https://api.deepseek.com/chat/completions
api_key   = 你的_key
api_model = deepseek-flash
并发数    = 4
图片最长边 = 1400
```

> **注意**：必须用支持读图的模型。实测 `deepseek-flash` 可以，
> `deepseek-v4-pro` **不支持读图**。
> 其他平台见网页版「设置」页里的对照表。

### 4. 使用

双击 `网页版.bat`（或 `启动.bat` 用命令行版），每周四步：

1. **建班级** —— 填班级名和这次考什么
2. **放照片** —— 照片放进 `答题卡照片\<班级>\<课次>\`，照片名用学生姓名
3. **识别 + 核对 + 登分** —— 核对表会直接出现在下面，红字分数可改
4. **一键生成** —— 成绩表、话术、小任务、群发文件夹一次出全

## 实测数据

```
真实使用：5 个班次 / 131 名学生
生成话术：112 条
个人小任务：65 份
群发文件：232 个
迭代次数：36 次（全部来自真实使用中暴露的问题）
```

**识别准确率**：24 张真实答题卡，**23 张分数完全正确（96%）**，
平均约 6 秒 / 张，24 张总耗时 141 秒。

> 所以系统**强制保留人工核对这一步** —— 分数是要发给家长的，
> 错一个数字就是一次事故。工具替老师干粗活，不替老师做决定。

## 技术要点

- **纯 Python 标准库 + 少量常用库**，无 Web 框架，无数据库，无 CDN
- 网页版服务端是 `http.server`，前端是原生 JS，单文件 `index.html`
- 所有数据都是**本地文本文件**（txt / xlsx / docx / json），随时可看可改
- 支持多平台视觉 API（DeepSeek / 通义千问 / 智谱 / Kimi），只需改配置
- 大题扣分采用**反推校验**：各大题扣分之和必须等于 `满分 − 分数`，
  对不上会自动标记「未定位」并告警
